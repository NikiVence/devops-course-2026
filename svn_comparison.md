# Git vs SVN: ключевые различия

## 1. Почему в Git ветвление дешёвое, а в SVN — дорогое?

**Git:**
- Ветка — это просто указатель на коммит (~41 байт).
- Создаётся мгновенно, локально.

**SVN:**
- Ветка — это копия директории на сервере.
- Требует сетевой операции и создания отдельной ревизии.

---

## 2. Можно ли в SVN закоммитить без интернета?

**Нет.** SVN централизованный:
- Репозиторий только на сервере, у тебя — рабочая копия.
- Коммит = отправка на сервер и создание новой ревизии.

**В Git — да**, потому что репозиторий полностью локальный.

---

## 3. Когда SVN всё ещё лучше Git?

- **Большие бинарные файлы** (без Git LFS).
- **Гранулярные права доступа** к отдельным папкам.
- **Legacy-проекты** и консервативный enterprise.
- **Простые линейные процессы** для маленьких команд.
- **Частичный чекаут** огромных репозиториев.
