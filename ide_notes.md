# Заметки об IDE: Git в VS Code

## Удобное в VS Code для работы с Git

1. **Встроенная панель Source Control (Ctrl+Shift+G)**
   Все изменения видны в одном месте: список изменённых файлов, разбитый на «Staged Changes» и «Changes». Можно просматривать диффы, кликая по файлам, и стейджить отдельные файлы или даже отдельные строки (через правый клик → Stage Selected Ranges), не переключаясь в терминал.

2. **Интерактивный diff и разрешение конфликтов**
   При конфликтах слияния VS Code показывает удобный трёхпанельный редактор с кнопками «Accept Current», «Accept Incoming», «Accept Both». Это заметно быстрее и нагляднее, чем вручную править маркеры `<<<<<<<` в текстовом редакторе.

3. **GitLens (или встроенный blame)**
   Аннотации прямо в редакторе показывают, кто и когда последний раз менял каждую строку, с возможностью посмотреть коммит. Плюс можно кликнуть по хешу и увидеть полную историю файла без выхода из IDE.

## Что удобнее в терминале

**Сложные операции с историей** — например, интерактивный rebase (`git rebase -i`), правка старых коммитов, `git filter-repo`, работа с reflog или cherry-pick диапазона коммитов. В терминале эти команды выполняются быстрее и точнее, чем через GUI, а вывод `git log --graph --oneline --all` даёт более полную картину истории, чем встроенный граф VS Code.
