# Подготовка к КР

## Когда rebase, когда merge?
Rebase — для своей неопубликованной ветки; merge — для объединения общей работы без переписывания существующих коммитов.

## Что произойдёт при rebase общей ветки?
Хеши коммитов изменятся, история коллег разойдётся с серверной. Потребуется согласование и перенос их работы; force push может потерять чужие изменения.

## Для чего multi-remote?
Для резервной копии на другом сервере, миграции хостинга и работы с форком: origin — своя копия, upstream — оригинал. Push в два адреса не атомарен, результат каждого нужно проверять.
